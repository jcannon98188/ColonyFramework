## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Spec section 6 makes Tier 1 bit-exact determinism the contract (ADR 0002): the same build, seed and inputs must hash identically across thread counts, SSE/AVX/AVX-512 and Windows/Linux x86-64. That is impossible if simulation code reaches MathF, Vector<T> or System.Random, so the Framework needs its own math layer before any System is written. Pathfinding costs, TilePos offsets and generation noise are specified as fixed-point, and all randomness is counter-based (Philox-like) addressed by (World seed, stream key, counter) so adding a consumer never shifts another consumer. The hash primitive used for World and chunk hashes belongs here too.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Fixed32 (16 fractional bits) and Fixed64 types with vector forms, deterministic trig and sqrt tables, and saturating conversions; golden-value tests cover edge cases (overflow, negative zero, rounding)
- [x] #2 A float math layer with a fixed logical SIMD width, fixed-tree reductions, no FMA contraction, defined float-to-int saturation and own transcendental functions; every SIMD path has a Vector128 fallback and tests prove the wide and fallback paths produce identical bits
- [x] #3 A counter-based RNG addressed by (seed, stream key, counter) with tests showing streams are independent and reproducible across runs and thread counts
- [x] #4 A hash primitive suitable for chunk and World hashing with committed golden hashes for fixed inputs
- [x] #5 Public API is safe (no pointers); the only unsafe code is internal

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Namespaces Colony.Numerics and Colony.Hashing (a Colony.Math namespace would shadow System.Math). Public types: Fixed32/Fixed64 with x2/x3 vectors, FloatMath (LaneCount 8, SimdPath Scalar/Vector128/Vector256 all bit-identical), Hash64/Hash64State (XXH64-compatible, published vectors pass), Philox4x32-10 RandomSource/RandomSequence (Random123 KATs pass; RandomStream renamed RandomSource because CA1711 bans the Stream suffix). Trig/sqrt tables generated by tools/scripts/gen_fixed_tables.py and committed as static readonly arrays because ReadOnlySpan RVA properties allocated under tier-0 JIT (caught by the alloc test). Fixed64 trig shares the 1024-step table (~2^-21 accuracy, documented). Float Sin/Cos domain |x|<2^24. Follow-up: TASK-6's internal Fnv1a layout hash should be replaced by Hash64 (changes schema hash values) when TASK-7 wires the World hash.
<!-- SECTION:NOTES:END -->
